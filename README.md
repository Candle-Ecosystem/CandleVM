# CandleVM

CandleVM is a Rust-based, language-independent bytecode virtual machine designed to execute compiled programs through a
common runtime.

It is part of the **Candle ecosystem**, providing the foundation for languages and tools targeting the Candle bytecode
format.

## Documentation

For more information, architecture details, bytecode specifications, and usage instructions, visit
the [CandleVM documentation](https://candle.nozyx.dev/docs/1/candlevm).
